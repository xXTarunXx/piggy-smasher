# Step 4 — Polish the first 30 seconds

## Goal
Make the first half-minute of play feel finished, and get the game into a state worth recording for a portfolio clip.

## Build this
1. A simple title/start screen (game title, a "Play" button — nothing elaborate).
2. UI polish: the coin count should animate/pop when it changes rather than snapping instantly (a short tween on the label is enough).
3. Balance pass: adjust piggy HP, coin values, and upgrade costs so a new player reaches their first upgrade purchase within roughly 20–30 seconds, and progress feels steady rather than stalling or trivializing.
4. Sweep for anything unfinished-looking left over from Steps 1–3: stray debug labels, placeholder text, console errors.

## Done when
Starting from the title screen and playing for 30–60 seconds feels like a complete, coherent slice — someone unfamiliar with the project should be able to pick it up and understand the loop without explanation.

## After this step (manual, not part of the build task)
Record a short screen capture of a satisfying sequence — ideally a rare piggy going down — for use as a portfolio/resume asset regardless of where the game ends up hosted.
